# Guía para publicar gratis la web ABARTOLOMEG

La web es estática: HTML, CSS e imágenes. No necesita WordPress, PHP, una base de datos ni plugins. GitHub Pages puede alojarla gratis en un repositorio público.

## A. Verla en el iMac
1. Descomprime `web-abartolomeg-maqueta.zip`.
2. Abre la carpeta `site-abartolomeg`.
3. Haz doble clic en `index.html`.
4. Revisa las secciones, especialmente las imágenes, el email y los enlaces.

## B. Publicación gratuita en GitHub Pages
1. Entra en tu cuenta de GitHub o crea una si no tienes.
2. Crea un repositorio público llamado `abartolomeg-web`.
3. Sube el contenido de la carpeta `site-abartolomeg` directamente a la raíz del repositorio: `index.html`, `assets/`, `RESUMEN-CONTENIDOS.md` y los archivos de instrucciones.
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`, y guarda.
6. GitHub mostrará la dirección gratuita del sitio cuando termine la publicación. Comprueba todos los enlaces y las imágenes en esa dirección.

Los nombres de menú pueden variar ligeramente según la interfaz de GitHub. No hace falta activar acciones, comprar hosting ni instalar un CMS.

## C. Conectar `www.abartolomeg.com`
No cambies los DNS todavía. Primero confirma que el dominio sigue registrado y que puedes entrar al panel de DonDominio. Cuando el sitio de prueba funcione, se puede añadir el dominio personalizado en la configuración de Pages y seguir exactamente los registros DNS que GitHub indique. Antes de cambiar nada, guarda una captura de la configuración DNS actual. La conexión del dominio no renueva ni sustituye el coste anual del propio dominio.

## D. Privacidad y datos personales
Antes de hacer pública la web, confirma el email de contacto y revisa qué información legal es obligatoria para tu actividad. Esta versión no incorpora formularios, analítica, publicidad ni tienda, lo que reduce la complejidad, pero no elimina necesariamente las obligaciones legales. No publiques un aviso legal genérico con datos inventados.
